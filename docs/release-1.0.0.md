# Ordo 1.0.0

Ordo 1.0.0 packages the offline planning workspace for Windows x64. Planners can draft a five-paragraph order and its annexes, manage organizations and their assigned ORBATs, coordinate tasks and timelines, and export orders from Export Studio in Word, PDF, or HTML.

**Operation Testify** is an optional fictional civil-support exercise. Choose **Dashboard → Create Testify example** to create an editable copy of the saved reference operation. It uses the bundled US Army Orders doctrine and includes 16 units, 24 tasks, six objectives, four phases, and 20 timeline events.

**Doctrine exchange** is available under **Doctrines**. Import or export an `.ordo-doctrine` package to transfer a doctrine and its managed assets.

**Symbol and ORBAT exchange** is available under **Symbols & ORBATs**. Choose **Export → Ordo JSON (reimportable)** to share an editable symbol or a complete map. Choose **Import JSON** in the receiving workspace to review the file and its linked records.

**Installation.** Download and run `Ordo Setup 1.0.0.exe`. The installer is unsigned. For an upgrade, save edits, back up the workspace in Settings, and close Ordo before installing. The source archive contains the matching project and dependency lockfile. Verify either download against `SHA256SUMS.txt`.
