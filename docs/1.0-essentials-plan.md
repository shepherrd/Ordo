Three concrete polish gaps were found and corrected in development:

1. Unapplied legacy symbol fields were protected for desktop close/restore but could still be bypassed by some local actions. Saved Symbol and Saved ORBAT save/publish, import, duplicate, delete, export, undo and replacement actions now wait for field resolution. Operation editors also protect unit/view/page switches, editor close and destructive symbol actions. Apply/Discard remain available and pending fields are highlighted. Visiting global pages or another open operation keeps the original editor alive.
2. Creating the first Saved ORBAT symbol override allocated a new definition identity, which could remount the field controls and erase another unapplied field. Controls now retain other pending fields while each field is explicitly applied; frozen base snapshots and other nodes remain unchanged.

3. The operation sidebar still displayed 0.6.4 while the global shell and application metadata reported 0.6.5. Both sidebar labels now use the existing application-info API, avoiding separately maintained version strings. Resolved pending-field warnings also clear automatically.
